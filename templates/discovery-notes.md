## Jobs-to-be-done

Write exactly 3 JTBD statements. Format: when ___, I want ___, so I can ___.

1. When [SITUATION — the context in which the job arises], I want [DESIRED ACTION OR TOOL BEHAVIOR], so I can [OUTCOME — the progress the user is hiring the product to make].
2. When [SITUATION], I want [DESIRED ACTION], so I can [OUTCOME].
3. When [SITUATION], I want [DESIRED ACTION], so I can [OUTCOME].

A JTBD is about the job, not the feature. "When I need to draft a contract clause, I want to search past contracts by clause type, so I can reuse language my firm already approved" is a job; "I want an AI contract writer" is a feature pitch.
