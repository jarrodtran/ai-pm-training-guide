# PM-Craft Templates

Fill-in-the-blank templates for the PM-craft deliverables of the AI-PM Graduate Program. Open the file for the deliverable you are working on, replace every [PLACEHOLDER] with your own content, and complete the "Done when" checklist at the bottom before calling the deliverable finished.

The templates map to the PM 501 — Product Management Fundamentals deliverables (course portfolio) and use the syllabus vocabulary: JTBD, PRD, user story, acceptance criteria (given/when/then), RICE, north star, guardrail metric, double diamond, definition of done.

## Using the templates

1. Read the deliverable line in the course syllabus first — the template follows its exact shape.
2. Replace every [PLACEHOLDER — WITH ITS INSTRUCTION]. The placeholder text is a requirement, not a suggestion.
3. Every template ends with a "Done when" checklist. It is the deliverable's test — if an item fails, the deliverable is not done.
4. If you cannot fill a placeholder, that is a finding, not a blank: record it as an open question with an owner and a date.

## Done when

- [ ] Every template file in this folder exists and matches the syllabus deliverable it serves
- [ ] Each template's own "Done when" checklist is completed before its deliverable is submitted
- [ ] No placeholder [BRACKETS] remain in any submitted deliverable
- [ ] Every open question named a placeholder has an owner and a date

## Style rules

- Plain professional markdown. No decorative flair, no color, no logos.
- Evidence over opinion: quotes, numbers, and sources — with source types where relevant.
- If a claim has no evidence, label it "ASSUMPTION" rather than letting it pass as fact.
